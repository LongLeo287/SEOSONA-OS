# Context-Sync & Engram: Agent Memory Systems

## context-sync
_Source: https://github.com/Intina47/context-sync_

Local persistent memory store for LLM applications (continue.dev, cursor, claude desktop, copilot, codex, antigravity).

## engram
_Source: https://github.com/Gentleman-Programming/engram_

Persistent memory system for AI coding agents. Agent-agnostic Go binary with SQLite + FTS5, MCP server, HTTP API, CLI, TUI.

## SEOSONA OS Relevance

- Both provide persistent memory patterns applicable to SEOSONA OS `3_MEMORY/` system
- engram's MCP server could integrate with SEOSONA capability bridge
- context-sync's approach to cross-agent memory sharing is relevant for multi-project contexts
