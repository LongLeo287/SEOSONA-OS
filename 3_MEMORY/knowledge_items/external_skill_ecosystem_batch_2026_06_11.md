## Learned Patterns

- Source-grounded research should use explicit source boundaries and browser-auth caution.
- Motion design needs a GSAP taxonomy: core, timeline, ScrollTrigger, plugins, frameworks, performance, and utilities.
- External web/social/video/podcast reach should expose channel readiness, auth mode, risk class, health check, and fallback.
- External skills must be security-gated for prompt injection, exfiltration, privilege escalation, supply chain, memory poisoning, tool misuse, and MCP permission abuse.
- Marketing skill routing should start with product marketing, audience, positioning, and proof before SEO, CRO, ads, copy, or lifecycle tasks.
- Managed-agent systems need task ownership, blocker reporting, status telemetry, skill compounding, and safe daemon/runtime boundaries.
- Sandboxed agent runtimes need network policy, credential isolation, lifecycle management, and retrieved-material compliance.
