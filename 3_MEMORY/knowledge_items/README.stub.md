# 3_MEMORY/knowledge_items/ — Private Directory

> **This directory is excluded from the public repo via `.gitignore`.**
> It is created automatically on first use and stores long-term memory data
> generated by SEOSONA OS agents during active sessions.

## What this directory contains (locally)

Long-term memory items accumulated by the SEOSONA OS agents:
- Structured knowledge extracted from UAP assimilation sessions
- Cross-session learnings and pattern libraries
- Agent self-improvement notes from post-session reviews
- Domain-specific intelligence built up over time

## How it gets populated

This directory is written to automatically by:
- `scripts/memory_logger.py` — logs events and learnings
- `1_CORE/workflows/post_session_learning.md` — end-of-session review
- `1_CORE/workflows/knowledge_ingestion_workflow.md` — UAP step 3 (LEARN)

## Structure (when populated)

```
3_MEMORY/knowledge_items/
├── seo/                    ← SEO domain knowledge
├── tech/                   ← Technical patterns learned
├── clients/                ← Per-client intelligence (private!)
└── meta/                   ← System self-improvement notes
```

> **Security note:** Never commit this directory. It may contain client-specific
> data, API response patterns, and personal workflow optimizations.
