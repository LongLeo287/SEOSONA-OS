## Learned Patterns

- Production skills should be trigger-focused workflows with anti-rationalization and evidence gates, not passive notes.
- HTML can be a durable portable artifact format for plans, reports, prototypes, and architecture diagrams when built as self-contained themed files.
- Harness-style work should preserve source-of-truth files, bounded implementation slices, independent review, and evidence packaging.
- Social publishing needs an explicit platform capability matrix and CLI-first workflow before browser automation or source spelunking.
- GA4 assistant setup generalizes into a connector template: preflight, OS/package manager detection, authentication, API enablement, script validation, and error recovery.
- Multi-agent work benefits from minimal status telemetry events, non-blocking hooks, wrappers for unsupported agents, and notification boundaries.
