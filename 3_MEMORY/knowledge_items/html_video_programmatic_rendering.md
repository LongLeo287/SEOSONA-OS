# html-video: Programmatic Video from HTML/CSS

_Source: https://github.com/nexu-io/html-video_

## Summary

Turn HTML, CSS & data into real MP4s. 21 built-in templates, pluggable render engines, AI soundtrack. Apache-2.0, no per-render fees.

## Key Features

- HTML/CSS to MP4 conversion
- 21 built-in templates
- Pluggable render engines
- AI-generated soundtracks
- Agent-friendly programmatic API
- No per-render pricing (Apache-2.0)

## SEOSONA Video Relevance

- **Alternative render engine** to MoviePy for template-based video creation
- Templates could replace `5_FRAMEWORK/templates/`
- Better for text-heavy content (thumbnails, title cards, lower thirds)
- Works well with BeVietnamPro font and SEOSONA brand colors
