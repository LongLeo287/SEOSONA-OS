## Durable Lessons

- Refero should remain the default design-research skill: styles define visual direction, screens define product patterns, and flows define journey logic.
- Production agent workflows should own prompts, context, tool schemas, control flow, human contact points, and durable event reducers.
- Away-from-keyboard harnesses should use separate implementer and reviewer stages, bounded loops, sentinels, validation gates, and strong sandbox rules.
- AuthKit implementations should keep API keys and authorization URL generation server-side, with exact redirect URI handling and secure cookie sessions.
- Anime.js V4 should be treated as a modular motion system with scoped imports, tree-shakeable primitives, and React cleanup via scopes.
- .NET microservices should pair service-owned data with gateway routing, RS256/JWKS auth, transactional outbox, DLQ operations, saga orchestration, and observability from the first vertical slice.
