# OmniVoice: High-Quality Voice Cloning for 600+ Languages

_Source: https://github.com/k2-fsa/OmniVoice_

## Summary

Voice cloning TTS by k2-fsa (Kaldi successor). Supports 600+ languages including Vietnamese.

## Key Features

- Zero-shot voice cloning
- 600+ language support
- High-quality neural synthesis
- Open source (k2-fsa ecosystem)

## SEOSONA Video Relevance

- **Alternative to VieNeu-TTS** for multilingual content
- Good for English-heavy scripts where VieNeu may not be optimal
- Could be used alongside VieNeu for best-of-both
