# KI: LongLeo287/Tiem_Nuoc_Nho_v5

## Overview
Hệ thống quản lý bán hàng (Point of Sale) đa nền tảng dành riêng cho Tiệm Nước Nhỏ, được thiết kế với tiêu chí: **Nhanh – Đẹp – Đa Năng**. Hệ thống kết hợp Frontend React linh hoạt cùng Backend Serverless (Google Apps Script) để tối ưu chi phí hạ tầng và đảm bảo quản lý dữ liệu realtime qua Google Sheets.
