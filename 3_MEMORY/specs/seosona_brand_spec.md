# SEOSONA Brand Specification

**Source:** `D:\Website SEOSONA\Guideline\SEOSONA DESIGN.md`
**Logged:** 2026-06-04

## 1. COLOR SYSTEM
- **Dark Blue 1 (Primary):** `#003566` (Used for dark mode backgrounds)
- **Green Accent:** `#46FF00` (Used for glows, outlines, and accents. NEVER use for primary solid buttons).
- **Charcoal:** `#091338` (Used for dark text on light backgrounds, though the site is now converting to full dark mode).

## 2. TYPOGRAPHY
- **Heading Font:** `Poppins` (Bold for H1, SemiBold for H2/H3).
- **Body Font:** `Inter` (Regular).

## 3. UI PATTERNS (Phase 2 Directive)
- **Glassmorphism:** Use `bg-white/5` with `backdrop-blur` for cards.
- **Buttons:** Primary buttons are pill-shaped (`rounded-full`) with Dark Blue background.
- **Accents:** Neon Green used for hover effects and micro-interactions.
