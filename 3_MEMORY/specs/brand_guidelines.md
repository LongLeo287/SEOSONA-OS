## 8. Content Rules

### Always Do
- Start with the benefit, then explain the feature
- Use real data and specific numbers
- Answer the core question in the first paragraph

### Never Do
- Use jargon without explanation
- Make claims without proof
- Use competitor brand names in copy

### Prohibited Phrases
- "synergy", "leverage", "game-changer"
- "simply" — implies it's easy when it might not be
