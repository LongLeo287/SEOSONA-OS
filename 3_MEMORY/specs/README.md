# Wings (Categories / Domains)

Wings represent broad, persistent categories or domains of knowledge for the developer's work (e.g., SEO, Frontend, CI-CD, Infrastructure, General Settings).

## How to use:
1. When learning about a specific project domain, create a file under this directory named after the domain (e.g., `seo-rebuild.md`).
2. Populate it with absolute verbatim facts, schemas, credentials, and constraints.
