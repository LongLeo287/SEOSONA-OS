# Ingestion Zone

This directory serves as the **Quarantine / Sandbox** of the SEOSONA System.

## Purpose:
- To temporarily store raw data: Images, PDFs, scraped links, or raw text files provided by the user.
- The system processes files here to execute the **UAP (Universal Assimilation Protocol)**.

## Principles:
- **NO PERMANENT STORAGE**: After the system has Analyzed -> Reviewed -> Learned (saving to `2_KNOWLEDGE`) -> Upgraded (creating Skills/Agents in `1_CORE`), all raw files and cloned repositories in this directory will be **DELETED** to free up space and maintain a clean system architecture.
- **READ-ONLY**: The system will only read and extract data from these files.
