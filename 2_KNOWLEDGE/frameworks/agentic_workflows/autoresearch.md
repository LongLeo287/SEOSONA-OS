# Autoresearch: Scientific Extraction

This skill allows the R&D Agent to automatically ingest arXiv papers and extract highly dense technical knowledge.

## Usage Directives
1. **Source Aggregation**: Query APIs (e.g. arXiv) for latest papers.
2. **LLM Filtering**: Filter out noise using strict relevance prompts.
3. **Synthesis**: Generate concise, actionable summaries for the user.

## Trigger Conditions
Activate when the user requests "research", "audit competitors structurally", or requires deep technical literature reviews.
