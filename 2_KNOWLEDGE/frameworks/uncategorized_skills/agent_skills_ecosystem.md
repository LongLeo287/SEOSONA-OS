# The Agent Skills Ecosystem

**Source:** Bulk Ingestion of 9 Repositories
**Assimilated Date:** Live Ingestion via UAP.

## 1. The Open Standard (`agentskills.io`)
Across multiple leading repositories (Anthropic, SEOSONA Awesome Skills, K-Dense-AI), the industry has converged on a standardized format for extending AI agent capabilities:
- **Format**: A folder containing a `SKILL.md` file (metadata + instructions) alongside optional `scripts/` and `assets/`.
- **Purpose**: Provides procedural knowledge and domain-specific context in a portable way, eliminating "agentic laziness" and ensuring repeatable, cross-platform workflows.

## 2. Methodology & Frameworks (Superpowers)
The **Superpowers** methodology (`obra/superpowers`) introduces an advanced execution framework:
- **Spec First**: The agent extracts a specification before jumping into code.
- **YAGNI & DRY Implementation Plan**: The plan is tailored for a "junior engineer" avoiding unnecessary abstractions.
- **Subagent-Driven Development**: Once approved, the orchestrator spawns specialized subagents to execute engineering tasks, inspecting and reviewing work dynamically (aligns with `claude_dynamic_workflows.md`).

## 3. Available Domain Libraries
Instead of storing thousands of individual `SKILL.md` files locally (which violates the Lean architecture), the SEOSONA system is now aware of external domain-specific libraries. When faced with a specialized task, the system can dynamically fetch logic from these catalogs:

### Engineering & General
- **Anthropic Official Skills** (`anthropics/skills`): Document creation (docx/pdf/xlsx) and baseline agent workflows.
- **SEOSONA Awesome Skills** (`sickn33/seosona-awesome-skills`): 1,500+ general-purpose agentic skills spanning multiple platforms (Claude Code, Cursor, SEOSONA).

### Specialized Domains
- **Cybersecurity** (`mukul975/Anthropic-Cybersecurity-Skills`): 754 production-grade security skills across 26 domains.
- **Marketing** (`coreyhaines31/marketingskills`): CRO, SEO, Analytics, and Content Strategy workflows.
- **Scientific/Research** (`K-Dense-AI/scientific-agent-skills`): 141 skills covering genomics, molecular dynamics, and database interactions.

### Integrations
- **Larksuite CLI** (`larksuite/cli`): 26 AI agent skills for interacting with Lark (Calendar, Drive, Messenger).
- **Obsidian** (`kepano/obsidian-skills`): Vault manipulation and note-taking integrations.

## 4. System Upgrade Integration
- The **Orchestrator Agent** must treat these repositories as external capability extensions. If a user requests a deep Cybersecurity audit, the Orchestrator should reference the patterns in `Anthropic-Cybersecurity-Skills`.
- **Skillization Rule**: Future skills generated by `create_skill_workflow.md` MUST follow the `agentskills.io` standard (`SKILL.md` inside a dedicated folder) to ensure cross-platform compatibility.
