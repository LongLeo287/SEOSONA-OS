# 🛠️ Skill: OpenHands Agent Architecture

> **Purpose**: Xây dựng hoặc thiết kế một luồng hệ thống AI Agent có khả năng tự trị cao dựa trên mô hình OpenHands (trước đây là OpenDevin).

## 📥 Inputs & Requirements
- **Input Format**: Bài toán cần hệ thống AI tự giải quyết (VD: Fix bug, build app).

## 🧠 Execution Steps (The Method)
1. **Containerized Sandbox**: Mọi hành động của Agent phải được thực thi trong môi trường cô lập (Docker) để bảo mật hệ thống host.
2. **Event Stream (Luồng sự kiện)**: Thiết kế hệ thống ghi nhận sự kiện (Action & Observation). Mỗi hành động (chạy lệnh bash, đọc file) trả về một kết quả quan sát.
3. **Looping Logic**: Agent đọc Observation hiện tại để quyết định Action tiếp theo, cho đến khi hoàn thành mục tiêu.
4. **Tool Use**: Trang bị cho Agent các công cụ: execute_bash, 
ead_file, write_file, rowse_web.

## 🛡️ Cognitive Guardrails
- **DO NOT**: Không cho phép Agent trực tiếp thực thi mã trên máy chủ thật mà không qua Sandbox.

## ✅ Quality Validation Criteria (MANDATORY)
*Before outputting "TASK COMPLETED", the agent MUST self-verify against these criteria:*
- [ ] Criteria 1: Có môi trường cô lập.
- [ ] Criteria 2: Vòng lặp dừng lại đúng lúc (không bị vô hạn).
