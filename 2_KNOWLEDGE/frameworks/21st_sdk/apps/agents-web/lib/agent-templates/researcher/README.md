# Researcher agent

An agent that researches topics on Wikipedia. Uses two tools:

- `wiki_search` — search Wikipedia for articles matching a query
- `wiki_article` — fetch the plain-text extract of a specific article

No API key required. Powered by the public Wikipedia API.

## Try it

- "Tell me about the James Webb Space Telescope"
- "Who invented the transistor?"
- "Summarize the Battle of Waterloo"
