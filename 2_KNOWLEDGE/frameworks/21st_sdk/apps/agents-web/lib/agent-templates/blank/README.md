# Blank agent

The smallest possible 21st agent. Start here if you want to build from scratch.

## What's in this template

- `agent/index.ts` — the agent definition (model, system prompt, no tools)
- `package.json` — just depends on `@21st-sdk/agent`

## Next steps

Ask the wizard to add a tool, change the system prompt, or set a different model. Every change autosaves and you can deploy whenever you're ready.
