# UI & Motion Design References

## Overview
Guidelines for generating state-of-the-art UI components, derived from top design galleries.

## Design Aesthetics (Mandatory)
1. **Vibrant & Premium**: Avoid generic bootstrap aesthetics. Use curated HSL palettes, sleek dark modes, and glassmorphism where appropriate.
2. **Typography**: Use modern Google Fonts (Inter, Roboto, Outfit) instead of browser defaults. Ensure proper descender spacing and hierarchy.
3. **Motion (MotionSites.ai)**: Interfaces must feel alive. Add subtle micro-animations for hover states, transitions, and loading skeletons.
4. **Refero Patterns**: Use established high-conversion layout patterns for landing pages (Hero -> Social Proof -> Features -> Interactive Demo -> CTA).
5. **No Placeholders**: Always generate working demonstrations or use the `generate_image` tool to create actual UI mockups instead of leaving `[Insert Image Here]`.

## SEO Best Practices
All generated UI code must include:
- Semantic HTML5 elements (`<article>`, `<nav>`, `<aside>`)
- Single `<h1>` per page
- Descriptive `alt` tags and `aria-labels`
