# Lazysizes

## Overview
High performance and SEO friendly lazy loader for images (responsive and normal), iframes and more, that detects any visibility changes triggered through user interaction, CSS or JavaScript without configuration.

## Core Value
- Improves Core Web Vitals (LCP) by deferring offscreen images.
- Automatically calculates the `sizes` attribute for responsive images.

## Integration Path
- Standardize this as the default lazy loading library for SEOSONA's frontend templates.
