# Knowledge Catalog (Google Cloud Platform)

## Overview
Knowledge Catalog (formerly Dataplex) is an AI-powered data catalog and metadata management platform by Google Cloud.

## Core Features
- Provides a dynamic knowledge graph of all data (structured and unstructured).
- Offers semantics and business context to AI agents.
- Provides tools, agents, and samples for context management, enrichment, and retrieval solutions.

*Source: github.com/GoogleCloudPlatform/knowledge-catalog*
