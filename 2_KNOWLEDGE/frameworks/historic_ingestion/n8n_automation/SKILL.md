## Overview
A fair-code licensed workflow automation tool, allowing you to connect APIs and build complex automations.

## Core Value
- Visual node-based workflow builder that can handle webhooks, API requests, and data transformations.
- Strong alternative to Zapier/Make with self-hosting capabilities, avoiding per-task execution costs.
