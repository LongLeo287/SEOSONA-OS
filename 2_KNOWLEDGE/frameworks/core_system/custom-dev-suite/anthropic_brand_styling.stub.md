## What this skill should contain

Anthropic's design system distilled for AI-native product styling:

- Color palette: cream/warm whites, deep charcoals, terracotta accent
- Typography: humanist sans-serifs with generous whitespace
- UI tone: calm, thoughtful, minimal — never "techy" or cold
- Iconography: simple line icons, no filled/heavy shapes
- Motion: subtle, purposeful — no gratuitous animation
- Writing style: direct, honest, no hype
