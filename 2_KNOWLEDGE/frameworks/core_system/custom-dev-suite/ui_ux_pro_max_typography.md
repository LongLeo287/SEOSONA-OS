# UI/UX Pro Max Typography

Display headings scale and descender spacing rules.

## 1. Font Display Scale
* Headings: bold, tight tracking (`tracking-[-0.03em]` to `tracking-[-0.04em]`).
* Display fonts: Geist Display, Satoshi, Outfit, Cabinet Grotesk.

## 2. Descender Spacing
* When using italic display titles, use a line height of at least `leading-[1.15]` or add padding bottom to avoid clipping descenders (such as `g, y, j, p, q`).
