## What this skill should contain

Guidelines distilled from Karpathy's approach to writing clean, minimal, high-signal code:

- **Think before coding** — state assumptions explicitly
- **Simplicity first** — minimum code to solve the problem
- **Surgical changes** — edit only what you must
- **Goal-driven execution** — quantitative success criteria
- **No speculative abstractions** — don't build what wasn't asked for
