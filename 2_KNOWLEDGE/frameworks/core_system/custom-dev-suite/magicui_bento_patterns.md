# MagicUI Bento Patterns

Bento grid layout and calibrated glow effects.

## 1. Bento Grid Ratios
* Avoid uniform, repetitive card grids. Alternate cell spans (e.g., col-span-2).
* Ensure at least 2-3 cards contain active visual assets (SVGs, screenshots, layouts).
* Cell count must match content; no empty cells are allowed.

## 2. Calibrated Glows
* Apply smooth border/background glows linked to the primary accent color.
* Glow opacity must not exceed 5-10%.
* Use hardware-accelerated mouse hover calculations.
