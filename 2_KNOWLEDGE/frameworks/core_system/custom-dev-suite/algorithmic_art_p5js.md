# Algorithmic Art p5.js

Generative computational art manifesto.

## 1. Seeded Randomness
Ensure all animations/generations are reproducible:
```javascript
let seed = 12345;
randomSeed(seed);
noiseSeed(seed);
```

## 2. Flow Fields
Prioritize organic complexity over static assets. Use noise octaves, particle trails, vector forces, and velocity-based color mappings.
