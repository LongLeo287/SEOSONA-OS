# Antigravity Awesome Skills

## Overview
A collection of advanced techniques for operating within the Antigravity IDE environment.

## Patterns
1. **Artifact Mastery**: Use artifacts for all structured, persistent data. Never dump 100 lines of JSON into the chat.
2. **Carousels**: Use Markdown carousels (` ```carousel `) to present sequential UI states or multi-step code diffs clearly.
3. **Task Checklists**: Keep `task.md` perfectly updated using `[ ]`, `[/]`, `[x]` syntax to ensure long-running tasks don't lose context.
4. **Slash Command Recommendations**: Proactively suggest `/goal` or `/schedule` when detecting long-running tasks or recurring needs.

## Usage
Whenever the user asks to "build a tool", "write a complex script", or "orchestrate agents", apply these Antigravity-specific patterns to ensure the output leverages the IDE's full capabilities.
