# UI/UX Pro Max Templates Index

This directory serves as a physical repository of premium React/Tailwind/Framer Motion templates extracted from top-tier UI libraries.

Do not write these from scratch. Import or copy the necessary `.tsx` code directly from these subdirectories when tasked with building user interfaces.

## 1. MagicUI Templates (`magicui/`)
Located at: `2_KNOWLEDGE/frameworks/react_components/ui_ux_pro_max_templates/magicui/`

**Key Components:**
- `bento-grid.tsx`: Advanced CSS grid layouts for modern dashboards.
- `magic-card.tsx`: Cards with mouse-following spotlight effects.
- `border-beam.tsx`: Animated glowing border tracer.
- `animated-shiny-text.tsx`: Apple-style shimmering text for taglines.
- `marquee.tsx`: Infinite horizontal/vertical scrolling container.
- `shimmer-button.tsx`: High-converting CTA button with edge glow.
- `retro-grid.tsx` / `dot-pattern.tsx`: High-end background patterns.

## 2. PrebuiltUI Templates (`prebuiltui/`)
Located at: `2_KNOWLEDGE/frameworks/react_components/ui_ux_pro_max_templates/prebuiltui/`

**Key Components:**
- Clean, accessible Buttons and Cards using Tailwind Merge (`cn`).
- Designed for rapid prototyping without heavy animation overhead.

## 3. Pattern-Craft Templates (`pattern-craft/`)
Located at: `2_KNOWLEDGE/frameworks/react_components/ui_ux_pro_max_templates/pattern-craft/`

**Key Components:**
- Advanced micro-interactions.
- `ads/CarbonAds.tsx`: Standardized ad placement patterns.
- `home/hero.tsx`: High-conversion hero section template with staggering animations.

> [!TIP]
> When executing UI tasks on user projects (like `SEOSONA Website`), read these source files using the `view_file` tool to understand their dependencies (`framer-motion`, `clsx`, `lucide-react`) before porting the code over.
