# WORKFLOW: Monthly Retainer Management

**Purpose:** Standardized monthly workflow for retainer clients to ensure consistent delivery, reporting, and value demonstration.

**Trigger:** 1st business day of each month for all active retainer clients.

## MONTHLY CYCLE

### Week 1: Planning & Analysis
- [ ] Pull previous month's performance data (GA4, GSC, Rank Tracker).
- [ ] Generate previous month's report using `report_generator` skill.
- [ ] Deliver report to client with `seo_reporting_sop` format.
- [ ] Analyze data to identify this month's priorities.
- [ ] Create monthly task plan (SEO actions, content calendar, technical fixes).
- [ ] Client meeting: Present last month results + this month plan.

### Week 2: Content & Technical Execution
- [ ] Publish scheduled content (blog posts, landing pages).
- [ ] Execute content review pipeline (`content_review_sop`).
- [ ] Implement technical SEO fixes from previous audit.
- [ ] Monitor keyword rankings for any anomalies.

### Week 3: Optimization & Outreach
- [ ] Analyze content performance from Week 2 publications.
- [ ] Optimize underperforming content (update, expand, re-optimize).
- [ ] Execute backlink outreach campaign (if in scope).
- [ ] Internal linking optimization pass (`internal_linking_optimizer`).

### Week 4: Review & Preparation
- [ ] Mid-cycle performance check.
- [ ] Prepare flash update for client.
- [ ] Document any issues or blockers for next month.
- [ ] Update project backlog with pending items.
- [ ] Pre-plan next month's content calendar.

## HEALTH METRICS
Track monthly for each retainer client:
- Organic Traffic Growth (MoM %)
- Keyword Ranking Distribution (Top 3/10/20)
- Content Published vs Planned
- Client Satisfaction Score (1-10)
- Revenue Attribution (if trackable)
