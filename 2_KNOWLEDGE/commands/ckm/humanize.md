# /humanize

Kích hoạt skill `ai_content_humanizer`.

## Input
- Văn bản cần humanize
- Tone (professional / casual / conversational)
- Ngôn ngữ (vi / en)
- Từ khóa SEO cần giữ (nếu có)

## Agent thực hiện
`copywriter`

## Output
- Văn bản đã humanize, tự nhiên, không bị phát hiện là AI
- Giữ nguyên từ khóa SEO và ý nghĩa gốc
