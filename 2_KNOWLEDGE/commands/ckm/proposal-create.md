# /proposal-create

Kích hoạt skill `proposal_generator` để tạo proposal cho khách hàng.

## Input cần cung cấp
- Tên khách hàng và ngành
- Dịch vụ yêu cầu
- Mục tiêu kinh doanh
- Ngân sách dự kiến (nếu biết)

## Agent thực hiện
`proposal-writer`

## Output
- Proposal Markdown hoàn chỉnh (Executive Summary, Methodology, Scope, Timeline, Pricing)
- Slide outline (nếu cần thuyết trình)
