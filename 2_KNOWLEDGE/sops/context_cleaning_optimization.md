# Context Cleaning Optimization SOP

## Purpose

Keep task context small enough for reliable execution while preserving the evidence needed to make correct changes.

## Process

1. Load contracts first: SOUL, MASTER_INDEX, project manifest, and AGENTS.
2. Use the capability bridge to route instead of reading every skill.
3. Read only files directly needed for the current task.
4. Prefer summaries for broad inventories and exact file reads for files that will be edited.
5. Before finalizing, verify with commands rather than relying on memory.
