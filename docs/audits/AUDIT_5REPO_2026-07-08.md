## Cross-cutting themes

1. **Doc-vs-reality drift is systemic.** Every repo's docs overstate/misstate reality:
   - OS: (recovery lore aside) —
   - Video: `tts_generator` node doesn't exist; OmniVoice is primary (docs say VieNeu); README counts unverified.
   - Content: README/roadmap claim multi-AI parallel + consensus — **code is single-provider only**; marked done = false.
   - UX-UI: README tier map wrong; "30+ components" = 28; "build passing" badge likely false.
   - Flow: **README describes a "stickman explainer" app that doesn't exist** — actual code is a TobyFlow automation fork.
2. **Tests/CI near-absent.** UX-UI 0, Content 0, Flow 0, Video 67 (not wired to `npm test`, no CI), OS 29 (thin for 111 scripts).
3. **OS-connector bugs hit every project.** `inferManifest` sets `typecheck`/`build` → `npm run typecheck|build` which exist in NO connected project (flagged in Content + Flow); rule template ends with a stray `TASK COMPLETED` line in every `AGENTS.md`; stack inference gives `["unknown"]` when there's no package.json at init time.
4. **Commit hygiene / worktree risk.** Video has 155 untracked functional `.py`; OS has uncommitted `bridge.js` + untracked `1_CORE/agents/`. Given the Antigravity worktree-wipe history, uncommitted functional code is a real data-loss risk.
5. **Junk/bloat.** Flow ~14 MB (`000008.ldb` leaking `_tobyConfigs`, `find_bounds.ps1`, 3.4 MB unreferenced `seosona-ux-ui/` with real client logos/PII); UX-UI 106 tracked `dist/` files; Content one corrupted prompt doc; Video stray `.obsidian/` + render outputs.
6. **Security is mostly good.** Video (no secrets, no shell injection, security tests), Content (no keys, output escaped, anti-fabrication guardrail), Flow (SSRF hardened, trusted-sender gates) are solid. Open items: OS leaked Google key in git history; Flow `<all_urls>` + cleartext `localhost:8080` default.

## SEOSONA OS core — findings

### P0 — unrecovered damage
- **`1_CORE/scripts/system_daemons/` gone entirely (10 daemons).** Deleted by the first Antigravity sweep `8e9de250b`, which predates every recovery baseline used this session — so recovery never covered it. Files: `eval_daemon` (de-faked this session to real py_compile+AST), `auto_linter_daemon`, `memory_compression_daemon`, `github_sync_daemon`, `dreaming_daemon`, `predictive_scanner`, `system_boot_manager`, `legacy_upgrade_engine`, `oa_academy_daemon`, `oap_intake_gateway`. Restorable from `8f6d35916`. (Decision: restore all vs. filter theatrical-sounding ones.)

### P1 — regressions / dirty state
- **`MIN_EXPECTED_SKILLS = 0`** in `seosona_capability_bridge.js:27` — Antigravity (`part 8`) committed this; the stale-router guard is disabled. Should be ~150.
- **`bridge.js` uncommitted local edits** (adds `4_AGENTS/personas` + `2_KNOWLEDGE/workflows` to graph collections + portability scan roots) alongside untracked `1_CORE/agents/` — in-progress work of unclear provenance; needs review then commit-or-revert.
- **Leaked Google API key still in git history** — needs `git filter-repo`/BFG + force-push + key revoke (history-rewrite = user decision).

### P2 — genuine upgrades
- **`1_CORE/scripts/core/mcp_client.py` is a stub** (`not_implemented` / `simulated:true`) — the OS cannot call MCP servers programmatically; only the Claude Code harness can. Implement the stdio JSON-RPC transport → OS dispatcher can use codebase-memory and other MCP tools.
- **No integrity guard** against external corruption. Add a guardian hook/daemon: detect mass-deletion commits ("deepest sweep"-class), block or alert; optionally checksum-verify critical paths on boot.
- **Connector fixes** (benefit all projects): make `inferManifest` emit real `typecheck`/`build` (or omit when absent instead of pointing to non-existent npm scripts); drop the `TASK COMPLETED` line from `buildRuleContent`; improve stack inference.
- **Thin tests** (29 for 111 scripts).
